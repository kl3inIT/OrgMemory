OrgMemory publishes a generated reference from the repository's committed OpenAPI contract. The reference is useful for discovering paths, request shapes, and response schemas; the surrounding guides define the security and product semantics that the schema alone cannot express.

<Callout type="warn" title="Treat the contract as deployment-scoped">
  Availability still depends on the enabled modules, your organization, and your permissions. A documented endpoint is not permission to access every resource it describes.
</Callout>

## Before you integrate

1. Read [Authentication and errors](/docs/developers/api-reference/authentication) for browser-session, CSRF, authorization, and error-handling expectations.
2. Choose the endpoint group below.
3. Confirm the operation against the exact OrgMemory release you deploy.
4. Exercise the flow in a non-production environment with a least-privilege identity.

## Endpoint groups

- [Administration](/docs/developers/api-reference/administration) — identity, roles, permissions, and organization controls.
- [Sources and connections](/docs/developers/api-reference/sources-connections) — source registration, credentials, crawl control, and access mapping.
- [Assets](/docs/developers/api-reference/assets) — governed assets, releases, delivery, and lifecycle operations.
- [Assistant](/docs/developers/api-reference/assistant) — conversations and permission-aware assistant tools.
- [Knowledge graph](/docs/developers/api-reference/knowledge-graph) — graph indexing, exploration, curation, and export.
- [Search and catalog](/docs/developers/api-reference/search-catalog) — retrieval, catalog browsing, and citation content.
- [Platform](/docs/developers/api-reference/platform) — session, organization context, health, and visible spaces.

## Generated-reference safety

The public schema replaces runtime server addresses with the reserved `example.invalid` domain and removes secret-bearing examples. The interactive playground is disabled. No production credential, private host, or deployment path is required to browse these pages.
