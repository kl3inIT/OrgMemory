Trang này ghi lại các phiên bản sản phẩm OrgMemory đã phát hành. Mỗi mục được
tổng hợp từ release note đã qua review, gắn với một phiên bản semantic duy nhất
và được công bố cùng bằng chứng build bất biến.

Phần nội dung chi tiết của từng release được giữ nguyên bằng tiếng Anh vì đây là
bản ghi chuẩn do Tegami sinh tự động. GitHub Releases là nguồn chuẩn cho ngày
phát hành, metadata của tag và file bằng chứng. Xem tại
[OrgMemory releases](https://github.com/kl3inIT/OrgMemory/releases).
