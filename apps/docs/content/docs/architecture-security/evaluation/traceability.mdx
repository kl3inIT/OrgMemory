## Traceability model

Each published requirement will link to a reader-visible behavior, responsible
component boundary, test or runtime evidence, and known limitation.

<VerificationBlock title="Honesty gate">
  A roadmap item, design, or unchecked plan is never presented as shipped
  behavior.
</VerificationBlock>
