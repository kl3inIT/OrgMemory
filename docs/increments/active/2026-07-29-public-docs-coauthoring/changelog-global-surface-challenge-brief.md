# Architecture challenge: Changelog as a global surface

Date: 2026-08-01

## Adversarial framing

The current Changelog is described as a global product surface, but Fumadocs
also exposes its generated release tree as a fifth root tab. A reader therefore
sees `Organizational AI Memory Release Notes` beside the four documentation
categories, which contradicts the intended information architecture. Hiding
the label without understanding the active-tab behavior can also make the
category selector disappear unexpectedly on Changelog routes.

## Product promise

- The category switcher contains exactly Getting Started, Product Guides,
  Architecture & Security, and Reference.
- Changelog remains a prominent localized global link.
- Changelog routes show only their generated local release navigation: Latest,
  recent versions, and Older releases.
- Tegami remains the sole generator of release entries and release navigation;
  publishing a release must not require editing React navigation code.
- Public copy uses `Organizational AI Memory`, never the repository shorthand.

## Exact proposed design

Treat Changelog as a standalone global surface. Keep its generated Fumadocs
root folder so the nearest-root page-tree context continues to focus the
sidebar on release links, but return `null` for that folder from
`DocsLayout.tabs.transform`. The four documentation roots remain the only
category tabs. On Changelog routes, the global Changelog link is active and the
release tree is visible; the category selector is intentionally absent because
the route does not belong to a documentation category. Readers return to docs
through the persistent Organizational AI Memory title or choose a category
after returning to the docs corpus.

The rejected implementation candidate is a custom Changelog layout that
duplicates the category selector with an unselected placeholder. It would need
to reproduce Fumadocs desktop/mobile sidebar, accessibility, locale, collapse,
and future upgrade behavior for a control that is semantically inapplicable.

## Current enforcement paths

- `apps/docs/src/app/[lang]/docs/layout.tsx` builds layout tabs from the page
  tree and owns the tab transform.
- `apps/docs/src/lib/layout.shared.tsx` owns the localized global Changelog
  link.
- `apps/docs/content/docs/changelog/meta*.json` is generated by Tegami and owns
  the focused release tree.
- `apps/docs/test/e2e/navigation.spec.ts` verifies the category switcher,
  localized global link, focused release tree, anchors, and archive route.
- `apps/docs/ARCHITECTURE.md` records the public information architecture.

## Motivating cost

Leaving the fifth selector item misrepresents product release history as a
reader task category and makes the switcher harder to scan. Building a custom
parallel docs layout carries recurring upgrade and accessibility cost. The
proposed filter is a small use of the framework's supported API, while E2E tests
make the intentional no-selector Changelog state explicit.
