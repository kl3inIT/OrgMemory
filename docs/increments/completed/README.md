# Completed Increments

Completed increment directories are immutable point-in-time evidence. Their
designs and plans explain what one delivery cycle intended and executed at that
time; they are expected to diverge as the product evolves.

Never use this directory to answer current behavior. Use:

- [ARCHITECTURE.md](../../../ARCHITECTURE.md) for current system and
  cross-subproject facts;
- [domain specs](../../specs/domains) for current behavior;
- [domain test matrices](../../tests/domains) for current coverage and gaps;
- [decisions](../../decisions) for why significant choices were made;
- [roadmap](../../roadmap.md) for delivery status and backlog.

Completed documents are not modernized, reworded, or given retroactive
checkmarks. A later correction belongs in the current living document or in a
new increment/decision that supersedes the old result.
